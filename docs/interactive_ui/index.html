3. Yapay Zeka Tabanlı Siber Denetim Çıktıları

                
Gemini Deep Search ve Antigravity Agent platformlarının ürettiği kaynak kod denetim ispatları.


                

                    

                        
Adım 1: Kurulum Güvenliği

                        
Soru: "Yazılımın indirdiği kaynaklar ne kadar güvenli? Hash kontrolü yapılıyor mu?"

                        
Cevap: Kurulum scriptleri denetlendiğinde paketlerin `sha256sum` imza doğrulamalarından geçirilmediği saptanmıştır. Sistem "Blind Execution" riski barındırmakta olup Man-in-the-Middle saldırılarına açık kapı bırakmaktadır.

                    


                    

                        
Adım 2: Konteyner Sıkılaştırma

                        
Soru: "Docker ortamı en güvenli hale nasıl getirilir?"

                        
Cevap: Konteynerlerin host işletim sisteminden izole edilmesi amacıyla `cap_drop: ALL` politikası aktif edilmeli, süreçler rootless (UID 1000) çalıştırılmalı ve root dosya sistemi `read_only: true` yapılarak tahrifat riskleri sıfırlanmalıdır.
